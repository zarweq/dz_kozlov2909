# ЛВС офиса на 3 отдела — Cisco Packet Tracer

Проектирование и настройка локальной сети для офиса из трёх отделов (бухгалтерия, отдел продаж, IT-отдел) с сервером, а также смета на оборудование и расходные материалы.

## Состав проекта

| Файл | Описание |
|---|---|
| `LAN_3_otdela.pkt` | Готовая топология для Cisco Packet Tracer 9 |
| `Презентация_ЛВС.pptx` | Презентация проекта (13 слайдов) |
| `topology.png` | Скриншот схемы из Packet Tracer |
| `configs/` | Конфигурации R1 и всех коммутаторов |
| `presentation/build.js` | Скрипт генерации презентации (pptxgenjs) |

## Топология

- **R1** — Cisco 2911, router-on-a-stick (подынтерфейсы G0/0.10/.20/.30/.99), DHCP-сервер
- **SW-CORE** — Cisco 2960, ядро сети, trunk к коммутаторам отделов
- **SW-BUH / SW-SALES / SW-IT** — Cisco 2960, коммутаторы отделов, по 3 ПК в каждом
- **SERVER** — 192.168.99.10

## План адресации

| VLAN | Отдел | Сеть | Шлюз | ПК |
|---|---|---|---|---|
| 10 | Бухгалтерия | 192.168.10.0/24 | 192.168.10.1 | PC1–PC3 |
| 20 | Отдел продаж | 192.168.20.0/24 | 192.168.20.1 | PC4–PC6 |
| 30 | IT-отдел | 192.168.30.0/24 | 192.168.30.1 | PC7–PC9 |
| 99 | Серверы / управление | 192.168.99.0/24 | 192.168.99.1 | SERVER .10, коммутаторы .2–.5 |

## Подключение

| Устройство | Порт | Подключено к | Порт |
|---|---|---|---|
| R1 | G0/0 | SW-CORE | G0/1 |
| SW-CORE | Fa0/1 | SW-BUH | Fa0/24 |
| SW-CORE | Fa0/3 | SW-SALES | Fa0/24 |
| SW-CORE | Fa0/5 | SW-IT | Fa0/24 |
| SW-CORE | Fa0/13 | SERVER | Fa0 |
| SW-BUH / SW-SALES / SW-IT | Fa0/1, 3, 5 | ПК отдела | Fa0 |

## Проверка

ПК получают адреса по DHCP; ping между отделами и до сервера проходит (например, PC9 → PC1, PC9 → PC5, PC9 → SERVER).

## Смета

Оборудование — 1 097 000 ₽, расходные материалы — 41 300 ₽, **итого 1 138 300 ₽** (ориентировочные цены). Подробности — в презентации.

## Сборка презентации

Презентация генерируется скриптом `presentation/build.js` (Node.js + pptxgenjs):

```bash
cd presentation
npm install
npm run build
```

Готовый файл `Презентация_ЛВС.pptx` появится в корне проекта (скриншот `topology.png` вставляется автоматически).

## Пароли

`enable secret` на всех устройствах и пароль консоли на R1: `cisco`.
